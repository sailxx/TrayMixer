# TrayMixer

**Steuern Sie die Lautstärke aller Ausgänge und Apps über ein kleines Bedienfeld in der Taskleiste Ihres Windows 11 oder Linux.**

Drehen Sie ein Spiel leiser, während Ihr Anruf hörbar bleibt, wechseln Sie zwischen Lautsprechern und Kopfhörern oder passen Sie Helligkeit, Blaulichtfilterung und Dimmung am Windows an.

**Keine Telemetrie oder Konto.** Open Source unter Apache 2.0.

<summary><b>Mehr zu den Funktionen</b></summary>

### Ausgänge und App-Lautstärke

Jeder Ausgang verfügt über einen eigenen Schieberegler und eine Stummschaltungssteuerung. Klicken Sie auf einen Ausgabenamen, um ihn als Standard auszuwählen. Beim Linux gilt dies für die neue Wiedergabe und jeder App-Stream erscheint separat.

### Windows-Anzeigesteuerung

Passen Sie die Helligkeit unterstützter Monitore an, erwärmen Sie das Display mit dem Blaulichtfilter und nutzen Sie die Software-Dimmung über denselben Mixer. [Sehen Sie sich den Windows-Screenshot in voller Größe an](assets/readme/screenshot.png).

### Fachsteuerung

Klicken Sie mit der linken Maustaste auf das Windows-Tray-Symbol, um den Mixer ein- oder auszublenden, und klicken Sie mit der mittleren Maustaste darauf, um den Standardausgang stummzuschalten. Scrollen Sie über eine Zeile, um sie um zwei Punkte anzupassen, klicken Sie auf das Symbol einer Audiozeile, um sie stummzuschalten, oder klicken Sie mit der rechten Maustaste auf eine Zeile, um sie auszublenden. Stellen Sie ausgeblendete Zeilen aus dem Taskleistenmenü wieder her. Drücken <kbd>Esc</kbd> oder klicken Sie außerhalb, um das Windows-Flyout zu schließen. Die Klicks im Linux-Tray hängen von Ihrem Desktop ab.

### Aussehen, Start und Vorlieben

Windows verwendet ein abgerundetes Flyout. Linux folgt den hellen, dunklen und Akzentfarben GNOME oder bietet Charcoal, Nord, Catppuccin und Light an. Sie können den Start beim Anmelden über das Taskleistenmenü aktivieren. Präferenzen werden lokal gespeichert.

<summary><b>Installieren</b></summary>

### Windows 11 · x64 · v3.0.2

1. Herunterladen [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) für einen Offline-Installer oder [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) um die App direkt auszuführen.
2. Wählen Sie im Setup Englisch oder Russisch, den Installationsordner und ob TrayMixer bei der Anmeldung gestartet werden soll. Die App-Oberfläche ist auf Englisch. Setup erstellt Desktop- und Startmenü-Verknüpfungen.
3. Klicken Sie im Benachrichtigungsbereich auf das TrayMixer-Symbol, um den Mixer zu öffnen.

Führen Sie das Setup erneut aus, um ein Update oder eine Neuinstallation durchzuführen und dabei die Einstellungen und die Autostart-Auswahl beizubehalten. Entfernen Sie die App über Windows **Installierte Apps**.

Die Versionen sind nicht signiert, daher zeigt Windows möglicherweise eine SmartScreen-Warnung an. Vergleichen Sie die Datei SHA -256 mit der [Windows-Versionshinweise](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Für eine unbeaufsichtigte Installation ohne Starten der App führen Sie Folgendes aus: `TrayMixer-Setup.exe /S /NOLAUNCH` aus dem Installationsordner. Optionale Schalter enthalten `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` Und `/LAUNCH`. Führen Sie zum unbeaufsichtigten Entfernen Folgendes aus: `Uninstall.exe /uninstall /S` aus dem Installationsordner, der standardmäßig lautet `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1-Vorschau

| Paket | Installieren oder starten Sie es über den Download-Ordner |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, Dann `./TrayMixer-3.1.1-x86_64.AppImage` |

Die Vorschau verwendet X11 oder XWayland und benötigt glibc 2.35 +, PulseAudio 15+ oder PipeWire-Pulse und `pactl`. GNOME erfordert AppIndicator-Unterstützung für das Taskleistensymbol. Der AppImage benötigt System-Desktop-Bibliotheken und akzeptiert `--appimage-extract-and-run` wenn FUSE nicht verfügbar ist.

Siehe die [Linux-Anleitung](linux/README.md) für Desktop-Anforderungen und Tray-Verhalten. Vergleichen Sie Paket-Hashes mit [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

</details>

<summary><b>Plattformen und bekannte Grenzen</b></summary>

| | Windows 11 | Linux-Vorschau |
| --- | --- | --- |
| Audio | Geräte- und gruppierte App-Lautstärke | Geräte und einzelne App-Streams über PulseAudio oder PipeWire-Pulse |
| Tablett | Windows-Benachrichtigungsbereich | Hängt vom Desktop-Tray-Host ab |
| Anzeige | Helligkeit, Blaulichtfilterung und Dimmung | Öffnet die Anzeige- und Nachtlichteinstellungen des Desktops |
| Präferenzen | `HKCU\Software\TrayMixer` | `$XDG_CONFIG_HOME/traymixer/settings.json` |

Die Monitor- und Treiberunterstützung wirkt sich auf die Helligkeit des Windows aus. Die Verpackung und der Start von Linux werden auf Ubuntu 24.04 überprüft. Fedora- und Debian-Installationen, das Verhalten des GNOME-Trays und die Hardwarekompatibilität müssen noch auf dem Desktop getestet werden.

<summary><b>Entwicklung</b></summary>

TrayMixer wird verwaltet von [Vlad (sailxx)](https://github.com/sailxx) unter dem [Apache-Lizenz 2.0](LICENSE).

Erstellen Sie Windows aus einem Klon mit der integrierten . NET Framework C#-Compiler.

```cmd
build.cmd
```

Erstellen Sie Linux mit . NET SDK 10.0 . Siehe die [Bau- und Verpackungsanleitung für Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Um die englische README-Grafik neu zu erstellen, verwenden Sie die Schriftarten Golos Text und JetBrains Mono in `tools/readme/.font` wie beschrieben in [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Um einen Download zu überprüfen, verwenden Sie `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` in PowerShell und vergleichen mit dem [Windows-Versionshinweise](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), oder nutzen `sha256sum <filename>` auf Linux und vergleichen mit [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer speichert Präferenzen lokal. Linux sendet Audiobefehle an Ihren konfigurierten PulseAudio- oder PipeWire-Pulse-Server. Siehe die [Datenschutzrichtlinie](PRIVACY.md) Und [Sicherheitspolitik](SECURITY.md). Für einen reproduzierbaren Fehler geben Sie die Version OS, den Desktop und die betroffene Hardware an [GitHub-Problem](https://github.com/sailxx/TrayMixer/issues).

</details>
