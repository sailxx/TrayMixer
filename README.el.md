# TrayMixer

**Ελέγξτε την ένταση του ήχου κάθε εξόδου και εφαρμογής από ένα μικρό πάνελ στο δίσκο συστήματος Windows 11 ή Linux.**

Απενεργοποιήστε ένα παιχνίδι ενώ διατηρείτε την κλήση σας ηχητική, αλλάξτε μεταξύ ηχείων και ακουστικών ή ρυθμίστε τη φωτεινότητα, το φιλτράρισμα του μπλε φωτός και τη μείωση της έντασης του φωτός στο Windows.

**Χωρίς τηλεμετρία ή λογαριασμό.** Ανοιχτός κώδικας κάτω από το Apache 2.0 .

### Έξοδοι και όγκος εφαρμογών

Κάθε έξοδος έχει το δικό της ρυθμιστικό και έλεγχο σίγασης. Κάντε κλικ σε ένα όνομα εξόδου για να το επιλέξετε ως προεπιλεγμένο. Στο Linux , αυτό ισχύει για νέα αναπαραγωγή και κάθε ροή εφαρμογής εμφανίζεται ξεχωριστά.

### Χειριστήρια οθόνης Windows

Ρυθμίστε τη φωτεινότητα στις υποστηριζόμενες οθόνες, θερμάνετε την οθόνη με το φίλτρο μπλε φωτός και χρησιμοποιήστε λογισμικό που μειώνει τη φωτεινότητα από τον ίδιο μίκτη. [Δείτε το στιγμιότυπο οθόνης Windows σε πλήρες μέγεθος](assets/readme/screenshot.png).

### Χειριστήρια δίσκου

Κάντε αριστερό κλικ στο εικονίδιο του δίσκου Windows για να εμφανίσετε ή να αποκρύψετε τον μίκτη και κάντε μεσαίο κλικ για να αλλάξετε τη σίγαση στην προεπιλεγμένη έξοδο. Κάντε κύλιση σε μια σειρά για να την προσαρμόσετε κατά δύο σημεία, κάντε κλικ στο εικονίδιο μιας σειράς ήχου για σίγαση ή κάντε δεξί κλικ σε μια σειρά για να την αποκρύψετε. Επαναφέρετε τις κρυφές σειρές από το μενού του δίσκου. Τύπος <kbd>Esc</kbd> ή κάντε κλικ έξω για να κλείσετε το Flyout Windows. Τα κλικ στο δίσκο Linux εξαρτώνται από την επιφάνεια εργασίας σας.

### Εμφάνιση, εκκίνηση και προτιμήσεις

Το Windows χρησιμοποιεί στρογγυλεμένο πτερύγιο. Το Linux ακολουθεί τα ανοιχτά, σκούρα και τονισμένα χρώματα GNOME ή προσφέρει Charcoal, Nord, Catppuccin και Light. Μπορείτε να ενεργοποιήσετε την εκκίνηση κατά τη σύνδεση από το μενού του δίσκου. Οι προτιμήσεις αποθηκεύονται τοπικά.

### Windows 11 · x64 · v3.0.2

1. Λήψη [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) για πρόγραμμα εγκατάστασης εκτός σύνδεσης ή [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) για να εκτελέσετε απευθείας την εφαρμογή.
2. Στο πρόγραμμα Εγκατάστασης, επιλέξτε Αγγλικά ή Ρωσικά, τον φάκελο εγκατάστασης και εάν θα εκκινήσετε το TrayMixer κατά την είσοδο. Η διεπαφή της εφαρμογής είναι στα Αγγλικά. Το Setup δημιουργεί συντομεύσεις επιφάνειας εργασίας και μενού Έναρξης.
3. Κάντε κλικ στο εικονίδιο TrayMixer στην περιοχή ειδοποιήσεων για να ανοίξετε το μίκτη.

Εκτελέστε ξανά το Setup για ενημέρωση ή επανεγκατάσταση διατηρώντας τις προτιμήσεις και την επιλογή αυτόματης εκκίνησης. Αφαιρέστε την εφαρμογή μέσω του Windows **Εγκατεστημένες εφαρμογές**.

Οι εκδόσεις είναι ανυπόγραφες, επομένως το Windows μπορεί να εμφανίσει μια προειδοποίηση SmartScreen. Συγκρίνετε το SHA -256 του αρχείου με το [Σημειώσεις έκδοσης Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Για εγκατάσταση χωρίς παρακολούθηση χωρίς εκκίνηση της εφαρμογής, εκτελέστε `TrayMixer-Setup.exe /S /NOLAUNCH` από το φάκελο του προγράμματος εγκατάστασης. Οι προαιρετικοί διακόπτες περιλαμβάνουν `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` και `/LAUNCH`. Για αφαίρεση χωρίς επίβλεψη, τρέξτε `Uninstall.exe /uninstall /S` από το φάκελο εγκατάστασης, ο οποίος έχει οριστεί ως προεπιλογή `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 προεπισκόπηση

| Πακέτο | Εγκαταστήστε ή εκκινήστε από το φάκελο λήψης |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, τότε `./TrayMixer-3.1.1-x86_64.AppImage` |

Η προεπισκόπηση χρησιμοποιεί X11 ή XWayland και χρειάζεται glibc 2.35 +, PulseAudio 15+ ή PipeWire-Pulse και `pactl`. Το GNOME απαιτεί υποστήριξη AppIndicator για το εικονίδιο του δίσκου. Το AppImage χρειάζεται βιβλιοθήκες επιτραπέζιου υπολογιστή συστήματος και δέχεται `--appimage-extract-and-run` εάν το FUSE δεν είναι διαθέσιμο.

Δείτε το [Οδηγός Linux](linux/README.md) για απαιτήσεις επιφάνειας εργασίας και συμπεριφορά δίσκου. Συγκρίνετε τους κατακερματισμούς πακέτων με [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>Ανάπτυξη</b></summary>

Το TrayMixer διατηρείται από [Vlad (sailxx)](https://github.com/sailxx) κάτω από το [Άδεια Apache 2.0](LICENSE).

Κατασκευάστε το Windows από έναν κλώνο με το ενσωματωμένο . NET Framework C# μεταγλωττιστής.

```cmd
build.cmd
```

Κατασκευάστε το Linux με . NET SDK 10.0 . Δείτε το [Οδηγός κατασκευής και συσκευασίας Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Για να δημιουργήσετε ξανά το αγγλικό έργο τέχνης README, χρησιμοποιήστε τις γραμματοσειρές Golos Text και JetBrains Mono στο `tools/readme/.font` όπως περιγράφεται στο [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Για να επαληθεύσετε μια λήψη, χρησιμοποιήστε `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` σε PowerShell και συγκρίνετε με το [Σημειώσεις έκδοσης Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), ή χρήση `sha256sum <filename>` στο Linux και συγκρίνετε με [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

Το TrayMixer αποθηκεύει τις προτιμήσεις τοπικά. Το Linux στέλνει εντολές ήχου στον διαμορφωμένο διακομιστή PulseAudio ή PipeWire-Pulse. Δείτε το [πολιτική απορρήτου](PRIVACY.md) και [πολιτική ασφάλειας](SECURITY.md). Για ένα αναπαραγόμενο σφάλμα, συμπεριλάβετε την έκδοση, OS , επιτραπέζιους υπολογιστές και το επηρεαζόμενο υλικό σε ένα [GitHub ζήτημα](https://github.com/sailxx/TrayMixer/issues).
