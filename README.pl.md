# TrayMixer

**Kontroluj głośność każdego wyjścia i aplikacji za pomocą jednego małego panelu w zasobniku systemowym Windows 11 lub Linux.**

Wyłącz grę, utrzymując słyszalność rozmowy, przełączaj między głośnikami i słuchawkami lub dostosuj jasność, filtrowanie i przyciemnianie niebieskiego światła w Windows.

**Brak telemetrii i konta.** Otwarte oprogramowanie pod Apache 2.0.

<summary><b>Więcej o funkcjach</b></summary>

### Dane wyjściowe i głośność aplikacji

Każde wyjście ma swój własny suwak i kontrolę wyciszenia. Kliknij nazwę wyjścia, aby wybrać ją jako domyślną. W przypadku Linux dotyczy to nowego odtwarzania i każdy strumień aplikacji pojawia się osobno.

### Sterowanie wyświetlaczem Windows

Dostosuj jasność na obsługiwanych monitorach, ogrzej wyświetlacz za pomocą filtra niebieskiego światła i użyj oprogramowania do przyciemniania z tego samego miksera. [Zobacz zrzut ekranu Windows w pełnym rozmiarze](assets/readme/screenshot.png).

### Sterowanie tacą

Kliknij lewym przyciskiem myszy ikonę Windows na pasku zadań, aby pokazać lub ukryć mikser, a następnie kliknij go środkowym przyciskiem, aby przełączyć wyciszenie domyślnego wyjścia. Przewiń wiersz, aby dostosować go o dwa punkty, kliknij ikonę wiersza audio, aby wyciszyć, lub kliknij wiersz prawym przyciskiem myszy, aby go ukryć. Przywróć ukryte wiersze z menu zasobnika. Naciskać <kbd>Wyjście</kbd> lub kliknij na zewnątrz, aby zamknąć menu wysuwane Windows. Kliknięcia tacy Linux zależą od komputera.

### Wygląd, uruchamianie i preferencje

Windows wykorzystuje zaokrąglone menu wysuwane. Linux podąża za jasnymi, ciemnymi i akcentowanymi kolorami GNOME lub oferuje Charcoal, Nord, Catppuccin i Light. Możesz włączyć uruchamianie przy logowaniu z menu na pasku zadań. Preferencje są przechowywane lokalnie.

<summary><b>Zainstalować</b></summary>

### Windows 11 · x64 · v3.0.2

1. Pobierać [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) dla instalatora offline lub [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) aby bezpośrednio uruchomić aplikację.
2. W ustawieniach wybierz język angielski lub rosyjski, folder instalacyjny i opcję uruchamiania TrayMixer przy logowaniu. Interfejs aplikacji jest w języku angielskim. Instalator tworzy skróty na pulpicie i w menu Start.
3. Kliknij ikonę TrayMixer w obszarze powiadomień, aby otworzyć mikser.

Uruchom ponownie Instalatora, aby zaktualizować lub zainstalować ponownie, zachowując preferencje i opcję automatycznego uruchamiania. Usuń aplikację poprzez Windows **Zainstalowane aplikacje**.

Wersje są niepodpisane, więc Windows może wyświetlać ostrzeżenie SmartScreen. Porównaj plik SHA -256 z [Informacje o wydaniu Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Aby przeprowadzić instalację nienadzorowaną bez uruchamiania aplikacji, uruchom `TrayMixer-Setup.exe /S /NOLAUNCH` z folderu instalacyjnego. Opcjonalne przełączniki obejmują `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` I `/LAUNCH`. Aby usunąć bez nadzoru, uruchom `Uninstall.exe /uninstall /S` z folderu instalacyjnego, którym jest domyślnie `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · Podgląd v3.1.1

| Pakiet | Zainstaluj lub uruchom z folderu pobierania |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, Następnie `./TrayMixer-3.1.1-x86_64.AppImage` |

Podgląd wykorzystuje X11 lub XWayland i wymaga glibc 2.35 +, PulseAudio 15+ lub PipeWire-Pulse, oraz `pactl`. GNOME wymaga obsługi AppIndicator dla ikony w zasobniku. AppImage potrzebuje systemowych bibliotek pulpitu i akceptuje `--appimage-extract-and-run` jeśli FUSE jest niedostępny.

Zobacz [Przewodnik Linux](linux/README.md) pod kątem wymagań komputera stacjonarnego i zachowania zasobnika. Porównaj skróty pakietów z [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>Rozwój</b></summary>

TrayMixer jest obsługiwany przez [Wład ( sailxx )](https://github.com/sailxx) pod [Licencja Apache 2.0](LICENSE).

Zbuduj Windows z klonu z wbudowanym plikiem . Kompilator C# NET Framework.

```cmd
build.cmd
```

Zbuduj Linux z . NET SDK 10.0 . Zobacz [Przewodnik po budowie i pakowaniu Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Aby odbudować angielską grafikę README, użyj czcionek Golos Text i JetBrains Mono w `tools/readme/.font` jak opisano w [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Aby zweryfikować pobranie, użyj `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` w PowerShell i porównaj z [Informacje o wydaniu Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), lub użyj `sha256sum <filename>` na Linux i porównaj z [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer przechowuje preferencje lokalnie. Linux wysyła polecenia audio do skonfigurowanego serwera PulseAudio lub PipeWire-Pulse. Zobacz [polityka prywatności](PRIVACY.md) I [polityka bezpieczeństwa](SECURITY.md). Aby uzyskać powtarzalny błąd, podaj wersję, OS, komputer stacjonarny i sprzęt, którego dotyczy problem, w pliku [Problem z GitHub](https://github.com/sailxx/TrayMixer/issues).

</details>
