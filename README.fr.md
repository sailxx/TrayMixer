# TrayMixer

**Contrôlez le volume de chaque sortie et application à partir d'un petit panneau dans votre barre d'état système Windows 11 ou Linux.**

Baissez un jeu tout en gardant votre appel audible, basculez entre les haut-parleurs et les écouteurs, ou réglez la luminosité, le filtrage de la lumière bleue et l'atténuation sur le Windows.

**Pas de télémétrie ni de compte.** Open source sous Apache 2.0 .

<summary><b>En savoir plus sur les fonctionnalités</b></summary>

### Sorties et volume de l'application

Chaque sortie possède son propre curseur et son propre contrôle de sourdine. Cliquez sur un nom de sortie pour le sélectionner par défaut. Sur le Linux, cela s'applique à la nouvelle lecture et chaque flux d'application apparaît séparément.

### Commandes d'affichage du Windows

Ajustez la luminosité sur les moniteurs pris en charge, réchauffez l'écran avec le filtre de lumière bleue et utilisez la gradation logicielle du même mélangeur. [Voir la capture d'écran du Windows en taille réelle](assets/readme/screenshot.png).

### Contrôles du bac

Cliquez avec le bouton gauche sur l'icône de la barre d'état Windows pour afficher ou masquer le mélangeur et cliquez dessus avec le bouton central pour activer la sourdine sur la sortie par défaut. Faites défiler une ligne pour l'ajuster de deux points, cliquez sur l'icône d'une ligne audio pour la désactiver ou cliquez avec le bouton droit sur une ligne pour la masquer. Restaurez les lignes masquées à partir du menu de la barre d'état. Presse <kbd>Échap</kbd> ou cliquez à l'extérieur pour fermer le menu déroulant Windows. Les clics du plateau Linux dépendent de votre bureau.

### Apparence, démarrage et préférences

Windows utilise un icône déroulante arrondie. Le Linux suit le GNOME dans les couleurs claires, foncées et accentuées ou propose Charcoal, Nord, Catppuccin et Light. Vous pouvez activer le démarrage lors de la connexion à partir du menu de la barre d'état système. Les préférences sont stockées localement.

<summary><b>Installer</b></summary>

### Windows 11 · x64 · v3.0.2

1. Télécharger [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) pour un installateur hors ligne ou [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) pour exécuter l'application directement.
2. Dans Configuration, choisissez Anglais ou Russe, le dossier d'installation et si vous souhaitez démarrer TrayMixer lors de la connexion. L'interface de l'application est en anglais. Le programme d'installation crée des raccourcis sur le bureau et le menu Démarrer.
3. Cliquez sur l'icône TrayMixer dans la zone de notification pour ouvrir le mixeur.

Exécutez à nouveau le programme d'installation pour mettre à jour ou réinstaller tout en conservant les préférences et le choix de démarrage automatique. Supprimez l'application via Windows **Applications installées**.

Les versions ne sont pas signées, donc le Windows peut afficher un avertissement SmartScreen. Comparez le SHA -256 du fichier avec le [Notes de version du Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Pour une installation sans assistance sans lancer l'application, exécutez `TrayMixer-Setup.exe /S /NOLAUNCH` à partir du dossier d'installation. Les commutateurs en option incluent `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` et `/LAUNCH`. Pour une suppression sans surveillance, exécutez `Uninstall.exe /uninstall /S` à partir du dossier d'installation, qui est par défaut `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · Aperçu v3.1.1

| Emballer | Installer ou lancer à partir du dossier de téléchargement |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, alors `./TrayMixer-3.1.1-x86_64.AppImage` |

L'aperçu utilise X11 ou XWayland et nécessite la glibc 2.35 +, PulseAudio 15+ ou PipeWire-Pulse, et `pactl`. GNOME nécessite la prise en charge d'AppIndicator pour l'icône de la barre d'état. Le AppImage nécessite des bibliothèques de bureau système et accepte `--appimage-extract-and-run` si FUSE n'est pas disponible.

Voir le [Guide Linux](linux/README.md) pour les exigences du bureau et le comportement de la barre d'état. Comparez les hachages de packages avec [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

La prise en charge du moniteur et du pilote affecte la luminosité du Windows. Le packaging et le démarrage du Linux sont vérifiés sur Ubuntu 24.04 . Les installations Fedora et Debian, le comportement du bac GNOME et la compatibilité matérielle nécessitent encore des tests sur le bureau.

<summary><b>Développement</b></summary>

TrayMixer est entretenu par [Vlad ( sailxx )](https://github.com/sailxx) sous le [Licence Apache 2.0](LICENSE).

Construisez Windows à partir d'un clone avec le fichier . Compilateur C# du framework NET.

```cmd
build.cmd
```

Construisez Linux avec . NET SDK 10.0 . Voir le [Guide de construction et d'emballage du Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Pour reconstruire l'illustration anglaise README, utilisez les polices Golos Text et JetBrains Mono dans `tools/readme/.font` comme décrit dans [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Pour vérifier un téléchargement, utilisez `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` dans PowerShell et comparer avec le [Notes de version du Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), ou utiliser `sha256sum <filename>` sur Linux et comparer avec [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer stocke les préférences localement. Le Linux envoie des commandes audio à votre serveur PulseAudio ou PipeWire-Pulse configuré. Voir le [politique de confidentialité](PRIVACY.md) et [politique de sécurité](SECURITY.md). Pour un bogue reproductible, incluez la version, OS , le bureau et le matériel concerné dans un [Problème GitHub](https://github.com/sailxx/TrayMixer/issues).

</details>
