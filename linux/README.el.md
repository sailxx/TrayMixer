# TrayMixer για Linux — Προεπισκόπηση 3.1.1

Μια ξεχωριστή θύρα επιτραπέζιου υπολογιστή C# / Avalonia. Η υπάρχουσα πηγή και το πρόγραμμα εγκατάστασης Windows δεν έχουν αλλάξει.

## Υποστηριζόμενη γραμμή βάσης

x86_64 Linux , glibc 2.35 +, X11 ή XWayland , PulseAudio 15+ ή PipeWire με `pipewire-pulse`, και `pactl`. Οι έλεγχοι κατασκευής και συσκευασίας εκτελούνται στο Ubuntu 24.04. Εξακολουθούν να απαιτούνται εγκατάσταση για συγκεκριμένη διανομή και αποδοχή επιτραπέζιου υπολογιστή GNOME. Αυτή είναι μια προεπισκόπηση, όχι μια αξίωση πλήρους ισοτιμίας Windows.

## Εγκαθιστώ

Κάντε λήψη ενός DEB , RPM ή AppImage από την έκδοση προεπισκόπησης Linux.

- Ubuntu/Debian: `sudo apt install ./TrayMixer_3.1.1_amd64.deb`
- Μαλακό καπέλλο: `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm`
- AppImage: `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, μετά τρέξε το. Απαιτεί σύστημα `pactl`, Βιβλιοθήκες X11, fontconfig, ICU και OpenSSL. Εγκαθιστώ `pulseaudio-utils` στο Ubuntu/Fedora. FUSE 2 ή `--appimage-extract-and-run` μπορεί να απαιτηθεί. Πακέτα AppImage . NET , όχι ο διακομιστής ήχου συστήματος ή οι βιβλιοθήκες επιφάνειας εργασίας.

Εκτόξευση **TrayMixer** από το μενού της εφαρμογής. Η πρώτη εκκίνηση ανοίγει το μίξερ. το κλείσιμο διατηρεί το εικονίδιο του δίσκου σε λειτουργία. Έξοδος από το μενού του δίσκου. Το GNOME Shell χρειάζεται επέκταση AppIndicator/StatusNotifier (το Ubuntu συνήθως περιλαμβάνει μία). Χωρίς κεντρικό υπολογιστή δίσκου, μην ενεργοποιείτε την αυτόματη εκκίνηση μόνο σε δίσκο. χρησιμοποιήστε το μενού της εφαρμογής για εκκίνηση. Η εκ νέου εκκίνηση ζητά από την υπάρχουσα διαδικασία να ανοίξει ξανά το παράθυρό της μέσω ενός τοπικού σωλήνα μόνο για τρέχοντα χρήστη.

## Έλεγχοι

- Η ενεργοποίηση δίσκου ανοίγει/κλείνει το μίξερ. Το μενού δίσκου προσφέρει Άνοιγμα μίκτη, σίγαση προεπιλεγμένης εξόδου, επαναφορά κρυφών σειρών, αυτόματη εκκίνηση και Έξοδος. Οι κεντρικοί υπολογιστές δίσκου επιφάνειας εργασίας ελέγχουν τη συμπεριφορά κλικ. Η ισοτιμία μεσαίου κλικ Windows δεν είναι εγγυημένη.
- Ρυθμιστικά εξόδου και ροής εφαρμογής: 0–100%, σίγαση, τροχός ποντικιού ±2. Η ρύθμιση της θετικής έντασης καταργεί ρητά τη σίγαση.
- Κάντε κλικ σε ένα όνομα εξόδου για να το ορίσετε ως προεπιλογή για νέα αναπαραγωγή. Τα υπάρχοντα ρεύματα δεν μετακινούνται αναγκαστικά.
- Κάντε δεξί κλικ σε μια σειρά για απόκρυψη. Η επαναφορά κρυφών σειρών επαναφέρει όλες τις σειρές. Οι ξεχωριστές ροές εμφανίζονται ξεχωριστά, συμπεριλαμβανομένων των ροών σε μη προεπιλεγμένες συσκευές.
- Η έναρξη κατά τη σύνδεση χρησιμοποιεί μια καταχώρηση αυτόματης εκκίνησης XDG. απενεργοποιημένο μέχρι να επιλεγεί. Το AppImage πρέπει να παραμείνει στη μόνιμη θέση του.
- Εμφάνιση: Το GNOME / Σύστημα ακολουθεί τα ανοιχτόχρωμα/σκούρα και τονισμένα χρώματα GNOME, ανανεώνονται ενώ ο μίξερ είναι ανοιχτός. Το παλαιότερο GNOME χωρίς υποστήριξη έμφασης χρησιμοποιεί μπλε. Τα Charcoal, Nord, Catppuccin και Light είναι ενσωματωμένα. Χωρίς Mica ή διαφάνεια ολόκληρου του παραθύρου.
- Ρυθμίσεις: `$XDG_CONFIG_HOME/traymixer/settings.json`, αθέτηση `~/.config/traymixer/settings.json`.

## Γνωστά κενά έναντι του Windows

Η ενσωματωμένη φωτεινότητα ανά οθόνη, η ισχύς του μπλε φωτός και τα ρυθμιστικά μείωσης της φωτεινότητας του λογισμικού δεν έχουν ακόμη μεταφερθεί. **Ρυθμίσεις οθόνης και νυχτερινού φωτός** Ανοίγει τις ρυθμίσεις GNOME / KDE. Η γενική ρύθμιση γάμμα δεν υπάρχει στο Wayland. Απαιτείται μια συγκεκριμένη υλοποίηση του συνθέτη. Δεν εκτελούνται αυθαίρετες προνομιακές εγγραφές ή αλλαγές αδειών. Η ακριβής τοποθέτηση αναδυόμενων παραθύρων, η απόρριψη απώλειας εστίασης και τα εφέ φόντου Windows δεν αναπαράγονται.

## Κατασκευάστε και επαληθεύστε

Απαιτεί . NET SDK 10.0 . Στο Linux , από έναν κλώνο:

```sh
cd TrayMixer
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet run --project linux/TrayMixer.Linux.csproj
# Packaging requires dpkg-deb, rpm/rpmbuild and curl:
bash linux/package.sh 3.1.1
```

Στην τρέχουσα μηχανή ανάπτυξης Windows:

```cmd
cd /d C:\Users\Vlad\sx\traymixer
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet publish linux/TrayMixer.Linux.csproj -c Release -r linux-x64 --self-contained true -o linux/artifacts/publish
```

Το Windows μπορεί να διασταυρώσει τη δημοσίευση δυαδικών αρχείων Linux αλλά δεν μπορεί να τα εκτελέσει ή να δημιουργήσει εγγενή πακέτα χωρίς περιβάλλον Linux. `.github/workflows/linux.yml` εκτελεί δοκιμές, πραγματική επανάληψη PulseAudio έναντι μηδενικής εξόδου, επικύρωση μεταδεδομένων πακέτου και έλεγχοι καπνού εκκίνησης Xvfb. Αυτά δεν αντικαθιστούν τη δοκιμή ενός πραγματικού δίσκου GNOME, θεμάτων, υλικού ή ακρόασης ήχου. Χρησιμοποιούνται ετικέτες απελευθέρωσης Linux `linux-v*` έτσι δεν ενεργοποιείται η υπάρχουσα ροή εργασιών έκδοσης Windows. Οι υπάρχουσες εκδόσεις Windows διατηρούνται.
