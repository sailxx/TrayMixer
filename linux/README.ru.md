# TrayMixer для Linux — предварительный просмотр 3.1.1

Отдельный настольный порт C#/Avalonia. Существующий исходный код и установщик Windows не изменились.

## Поддерживаемая базовая версия

x86_64 Linux, glibc 2.35+, X11 или XWayland, PulseAudio 15+ или PipeWire с `pipewire-pulse`, и `pactl`. Проверки сборок и пакетов выполняются на Ubuntu 24.04. По-прежнему требуются установка конкретного дистрибутива и принятие рабочего стола GNOME; это предварительный просмотр, а не претензия на полную четность Windows.

## Установить

Загрузите DEB, RPM или AppImage из предварительной версии Linux.

- Убунту/Дебиан: `sudo apt install ./TrayMixer_3.1.1_amd64.deb`
- Федора: `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm`
- AppImage: `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, затем запустите его. Требуется система `pactl`, Библиотеки X11, Fontconfig, ICU и OpenSSL. Установить `pulseaudio-utils` в Ubuntu/Fedora. FUSE 2 или `--appimage-extract-and-run` может потребоваться. Пакеты AppImage. NET , а не системный аудиосервер или библиотеки рабочего стола.

Запуск **TrayMixer** из меню приложения. Первый запуск открывает микшер; при его закрытии значок в трее продолжает работать. Выход из меню в трее. GNOME Shell требуется расширение AppIndicator/StatusNotifier (обычно в Ubuntu оно имеется). Без хоста лотка не включайте автозапуск только для лотка; используйте меню приложения для запуска. При повторном запуске существующий процесс просит повторно открыть свое окно через локальный канал, доступный только текущему пользователю.

## Элементы управления

- Активация лотка открывает/закрывает миксер. Меню на панели задач предлагает открыть микшер, отключить звук по умолчанию, восстановить скрытые строки, автозапуск и выход. Хосты панели рабочего стола контролируют поведение щелчков; Windows Четность среднего щелчка не гарантируется.
- Ползунки вывода и потока приложений: 0–100 %, отключение звука, колесо мыши ±2. Установка положительной громкости явно включает звук.
- Щелкните имя вывода, чтобы сделать его значением по умолчанию для нового воспроизведения. Существующие потоки не перемещаются принудительно.
- Щелкните правой кнопкой мыши строку, чтобы скрыть ее; Восстановить скрытые строки возвращает все строки. Отдельные потоки отображаются отдельно, включая потоки на устройствах не по умолчанию.
- Запуск при входе в систему использует запись автозапуска XDG; отключено, пока не выбрано. AppImage должен оставаться на своем постоянном месте.
- Внешний вид: GNOME / Система соответствует светлым/темным цветам и акцентным цветам GNOME, обновляется при открытом микшере. Более старый GNOME без поддержки акцентов использует синий цвет. Встроены Charcoal, Nord, Catppuccin и Light. Никакой слюды и прозрачности всего окна.
- Настройки: `$XDG_CONFIG_HOME/traymixer/settings.json`, по умолчанию `~/.config/traymixer/settings.json`.

## Известные пробелы по сравнению с Windows

Встроенные ползунки яркости для каждого монитора, интенсивности синего света и программного затемнения еще не перенесены. **Настройки дисплея и ночного освещения** вместо этого открывает настройки GNOME/KDE. Универсальной регулировки гаммы на Wayland не существует; необходима реализация, специфичная для композитора. Никакие произвольные привилегированные записи или изменения разрешений не выполняются. Точное размещение всплывающего окна, закрытие фокуса и эффекты фона Windows не воспроизводятся.

## Создайте и проверьте

Требует . NET SDK 10.0 . На Linux, из клона:

```sh
cd TrayMixer
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet run --project linux/TrayMixer.Linux.csproj
# Packaging requires dpkg-deb, rpm/rpmbuild and curl:
bash linux/package.sh 3.1.1
```

На текущей машине разработки Windows:

```cmd
cd /d C:\Users\Vlad\sx\traymixer
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet publish linux/TrayMixer.Linux.csproj -c Release -r linux-x64 --self-contained true -o linux/artifacts/publish
```

Windows может осуществлять перекрестную публикацию двоичных файлов Linux, но не может выполнять их или создавать собственные пакеты без среды Linux. `.github/workflows/linux.yml` запускает тесты, реальное обратное чтение PulseAudio с нулевым выводом, проверку метаданных пакета и дымовые проверки запуска Xvfb. Они не заменяют тестирование реального лотка GNOME, тем, оборудования или прослушивания звука. Использование тегов выпуска Linux `linux-v*` поэтому существующий рабочий процесс выпуска Windows не запускается. Существующие выпуски Windows сохраняются.
