# TrayMixer для Linux — 3.1.1 попередній перегляд

Окремий порт C# / Avalonia для робочого столу. Існуюче джерело та програма встановлення Windows не змінені.

## Підтримувана базова лінія

x86_64 Linux , glibc 2.35 +, X11 або XWayland , PulseAudio 15+ або PipeWire з `pipewire-pulse`, і `pactl`. Перевірки складання та пакетів виконуються на Ubuntu 24.04. Потрібна інсталяція для конкретного дистрибутиву та прийняття GNOME для робочого столу; це попередній перегляд, а не заява про повний паритет Windows.

## встановити

Завантажте DEB, RPM або AppImage із попереднього випуску Linux.

- Ubuntu/Debian: `sudo apt install ./TrayMixer_3.1.1_amd64.deb`
- Fedora: `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm`
- AppImage: `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, потім запустіть його. Потрібна система `pactl`, Бібліотеки X11, fontconfig, ICU і OpenSSL. встановити `pulseaudio-utils` на Ubuntu/Fedora. FUSE 2 або `--appimage-extract-and-run` може знадобитися. Пучки AppImage. NET , а не системний аудіосервер чи бібліотеки робочого столу.

Запуск **TrayMixer** з меню програми. Перший запуск відкриває змішувач; якщо його закрити, піктограма в треї продовжує працювати. Вийти з меню трея. GNOME Shell потребує розширення AppIndicator/StatusNotifier (Ubuntu зазвичай включає таке розширення). Без хоста трея не вмикайте автозапуск лише трея; використовуйте меню програми для запуску. Повторний запуск вимагає від існуючого процесу повторно відкрити своє вікно через локальний канал, призначений лише для поточного користувача.

## Елементи керування

- Активація лотка відкриває/закриває міксер. Меню панелі пропонує відкрити мікшер, вимкнення звуку за замовчуванням, відновлення прихованих рядків, автозапуск і вихід. Хости панелі робочого столу контролюють поведінку клацань; Парність середнього клацання Windows не гарантується.
- Повзунки виведення та потоку програм: 0–100%, вимкнення звуку, коліщатко миші ±2. Встановлення позитивної гучності явно вмикає звук.
- Клацніть назву виводу, щоб зробити її типовою для нового відтворення. Існуючі потоки не переміщуються примусово.
- Клацніть правою кнопкою миші рядок, щоб приховати; Відновити приховані рядки повертає всі рядки. Окремі потоки відображаються окремо, включаючи потоки на нестандартних пристроях.
- Початок під час входу використовує запис автозапуску XDG; вимкнено до вибору. AppImage має залишатися на своєму постійному місці.
- Зовнішній вигляд: GNOME / Система наслідує світлі/темні кольори та акцентні кольори GNOME, оновлені, коли змішувач відкритий. Старий GNOME без підтримки акценту використовує синій колір. Вбудовані Charcoal, Nord, Catppuccin і Light. Без слюди або прозорості всього вікна.
- Налаштування: `$XDG_CONFIG_HOME/traymixer/settings.json`, за замовчуванням `~/.config/traymixer/settings.json`.

## Відомі прогалини порівняно з Windows

Інтегрована яскравість для кожного монітора, потужність синього світла та повзунки програмного затемнення ще не перенесені. **Налаштування дисплея та нічного освітлення** натомість відкриває налаштування GNOME / KDE. У Wayland немає універсального регулювання гами; необхідна спеціальна реалізація композитора. Довільні привілейовані записи або зміни дозволів не виконуються. Точне розміщення спливаючих вікон, усунення втрати фокусу та ефекти фону Windows не відтворюються.

## Побудуйте та перевірте

Вимагає . NET SDK 10.0 . На Linux , з клону:

```sh
cd TrayMixer
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet run --project linux/TrayMixer.Linux.csproj
# Packaging requires dpkg-deb, rpm/rpmbuild and curl:
bash linux/package.sh 3.1.1
```

На поточній машині розробки Windows:

```cmd
cd /d C:\Users\Vlad\sx\traymixer
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet publish linux/TrayMixer.Linux.csproj -c Release -r linux-x64 --self-contained true -o linux/artifacts/publish
```

Windows може перехресно публікувати двійкові файли Linux, але не може виконувати їх або створювати рідні пакунки без середовища Linux. `.github/workflows/linux.yml` запускає тести, справжнє зчитування PulseAudio проти нульового виводу, перевірку метаданих пакетів і перевірки запуску Xvfb. Вони не замінюють тестування справжньої панелі GNOME, тем, апаратного забезпечення чи прослуховування аудіо. Використання тегів випуску Linux `linux-v*` тому існуючий робочий процес випуску Windows не запускається. Існуючі версії Windows зберігаються.
