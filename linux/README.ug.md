# Linux ئۈچۈن TrayMixer - 3.1.1 ئالدىن كۆرۈش

ئايرىم C # / Avalonia ئۈستەلئۈستى ئېغىزى. ھازىر بار بولغان Windows مەنبەسى ۋە قاچىلىغۇچ ئۆزگەرمەيدۇ.

## قوللايدىغان ئاساسىي سىزىق

x86_64 Linux ، glibc 2.35 +, X11 ياكى XWayland ، PulseAudio 15+ ياكى PipeWire بىلەن `pipewire-pulse`, ۋە `pactl`. ئۇبۇنتۇ 24.04 دا ئىجرا بولىدۇ. تارقىتىشقا خاس قاچىلاش ۋە GNOME ئۈستەل يۈزى قوبۇل قىلىش يەنىلا تەلەپ قىلىنىدۇ بۇ ئالدىن كۆرۈش ، تولۇق Windows باراۋەرلىكى تەلىپى ئەمەس.

## قاچىلاش

Linux ئالدىن كۆرۈشتىن DEB ، RPM ياكى AppImage نى چۈشۈرۈڭ.

- Ubuntu / Debian: `sudo apt install ./TrayMixer_3.1.1_amd64.deb`
- Fedora: `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm`
- AppImage: `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, ئاندىن ئىجرا قىلىڭ. سىستېما تەلەپ قىلىدۇ `pactl`, X11 كۈتۈپخانىلىرى ، خەت نۇسخىسى ، ICU ۋە OpenSSL. قاچىلاش `pulseaudio-utils` ئۇبۇنتۇ / Fedora دا. FUSE 2 ياكى `--appimage-extract-and-run` تەلەپ قىلىنىشى مۇمكىن. AppImage باغلام. NET ، سىستېما ئاۋاز مۇلازىمېتىرى ياكى ئۈستەل ئامبىرى ئەمەس.

قوزغىتىش **TrayMixer** قوللىنىشچان تىزىملىكتىن. تۇنجى قويۇپ بېرىش ئارىلاشتۇرغۇچنى ئاچىدۇ. ئۇنى تاقاش تەخسە سىنبەلگىسىنى ئىجرا قىلىدۇ. تەخسە تىزىملىكىدىن چېكىنىش. GNOME Shell AppIndicator / StatusNotifier كېڭەيتىلمىسىگە ئېھتىياجلىق (ئۇبۇنتۇ ئادەتتە بىرنى ئۆز ئىچىگە ئالىدۇ). تەخسە ساھىبى بولمىسا ، پەقەت تەخسە ئاپتوماتىك قوزغىتىشنى قوزغىتىڭ. قوزغىتىش تىزىملىكىنى ئىشلىتىپ قوزغىتىڭ. قوزغىتىش ھازىر بار بولغان جەرياننى نۆۋەتتىكى ئىشلەتكۈچىگىلا ئىشلىتىلىدىغان يەرلىك تۇرۇبا ئارقىلىق كۆزنەكنى قايتا ئېچىشنى تەلەپ قىلىدۇ.

## كونتروللار

- تەخسە قوزغىتىش ئارىلاشتۇرغۇچنى ئاچىدۇ / تاقايدۇ. تەخسە تىزىملىكى ئوچۇق ئارىلاشتۇرغۇچ ، سۈكۈتتىكى ئاۋازسىز ئاۋاز ، يوشۇرۇن قۇرلارنى ئەسلىگە كەلتۈرۈش ، ئاپتوماتىك قوزغىتىش ۋە چېكىنىش بىلەن تەمىنلەيدۇ. ئۈستەل يۈزى تەخسىسى چېكىش ھەرىكىتىنى كونترول قىلىدۇ. Windows ئوتتۇرا چېكىشنىڭ باراۋەرلىكى كاپالەتكە ئىگە ئەمەس.
- چىقىرىش ۋە قوللىنىش ئېقىمى سىيرىلغۇچ:% 0-100 ، ئۈنسىز ، مائۇس چاقى ± 2. ئاكتىپ ئاۋازنى ئېنىق بەلگىلەش.
- چىقىرىش نامىنى چېكىپ يېڭى قويۇشنىڭ سۈكۈتتىكى ھالىتى قىلىڭ. ھازىر بار بولغان ئېقىنلار مەجبۇرىي يۆتكەلمەيدۇ.
- يوشۇرۇش ئۈچۈن قۇرنى ئوڭ چېكىڭ. يوشۇرۇن قۇرلارنى ئەسلىگە كەلتۈرۈش بارلىق قۇرلارنى قايتۇرىدۇ. ئايرىم ئېقىنلار ئايرىم كۆرسىتىلىدۇ ، بۇنىڭ ئىچىدە سۈكۈتتىكى ئۈسكۈنىلەردىكى ئېقىنلارمۇ بار.
- كىرىشتىن باشلىغاندا XDG ئاپتوماتىك قوزغىتىش پروگراممىسى ئىشلىتىلىدۇ. تاللانغانغا قەدەر چەكلەنگەن. AppImage چوقۇم ئۆزىنىڭ مەڭگۈلۈك ئورنىدا تۇرۇشى كېرەك.
- سىرتقى كۆرۈنۈشى: GNOME / سىستېما سۇس / قاراڭغۇ ۋە GNOME تەلەپپۇزى رەڭگىگە ئەگىشىدۇ ، ئارىلاشتۇرغۇچ ئوچۇق ۋاقىتتا يېڭىلاندى. كونا GNOME تەلەپپۇزىنى قوللىماي كۆك ئىشلىتىدۇ. كۆمۈر ، Nord ، Catppuccin ۋە Light قاتارلىقلار ياسالغان. مىكا ياكى پۈتۈن كۆزنەكنىڭ سۈزۈكلۈكى يوق.
- تەڭشەك: `$XDG_CONFIG_HOME/traymixer/settings.json`, كۆڭۈلدىكى `~/.config/traymixer/settings.json`.

## Windows بىلەن بولغان پەرقلەر

ئېكراننىڭ بىر گەۋدىلەشتۈرۈلگەن يورۇقلۇقى ، كۆك نۇرنىڭ كۈچلۈكلۈكى ۋە يۇمشاق دېتال غۇۋا سىيرىلغۇچ تېخىچە ئۇلانمىدى. **كۆرسىتىش ۋە كەچلىك يورۇقلۇق تەڭشىكى** ئۇنىڭ ئورنىغا GNOME / KDE تەڭشىكىنى ئاچىدۇ. ئۇنىۋېرسال گامما تەڭشەش Wayland دا مەۋجۇت ئەمەس كومپوزىتورغا خاس يولغا قويۇش كېرەك. خالىغانچە ئىمتىيازلىق يازما ياكى ئىجازەت ئۆزگەرتىش ئېلىپ بېرىلمايدۇ. ھەقىقىي قاڭقىش ئورۇنلاشتۇرۇش ، فوكۇسنى يوقىتىش ۋە Windows ئارقا كۆرۈنۈش ئۈنۈمى كۆپەيتىلمەيدۇ.

## قۇرۇش ۋە دەلىللەش

تەلەپ قىلىدۇ. NET SDK 10.0. Linux دە ، كلوندىن:

```sh
cd TrayMixer
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet run --project linux/TrayMixer.Linux.csproj
# Packaging requires dpkg-deb, rpm/rpmbuild and curl:
bash linux/package.sh 3.1.1
```

ھازىرقى Windows ئېچىش ماشىنىسىدا:

```cmd
cd /d C:\Users\Vlad\sx\traymixer
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
dotnet publish linux/TrayMixer.Linux.csproj -c Release -r linux-x64 --self-contained true -o linux/artifacts/publish
```

Windows Linux ئىككىلىك سىستېمىنى ئۆزئارا تارقىتالايدۇ ، ئەمما Linux مۇھىتى بولمىسا ئىجرا قىلالمايدۇ ياكى يەرلىك ئورالمىلارنى قۇرالمايدۇ. `.github/workflows/linux.yml` سىناقنى ئىجرا قىلىدۇ ، ھەقىقىي PulseAudio قايتا ئوقۇشتىن قۇرۇق ، چىقىرىش مېتا سانلىق مەلۇمات دەلىللەش ۋە Xvfb قويۇپ بېرىش ئىس-تۈتەكلىرىنى تەكشۈرۈش. بۇلار ئەمەلىي GNOME تەخسە ، تېما ، قاتتىق دېتال ياكى ئاۋاز ئاڭلاشنىڭ ئورنىنى ئالمايدۇ. Linux ئېلان خەتكۈچلىرى ئىشلىتىلىدۇ `linux-v*` شۇڭا ھازىر بار بولغان Windows قويۇپ بېرىش خىزمەت ئېقىمى قوزغىتىلمىدى. ھازىر بار بولغان Windows ئېلان قىلىنغان.
