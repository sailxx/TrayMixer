<summary><b>Tuilleadh faoi na gnéithe</b></summary>

### Aschuir agus toirt app

Tá a shleamhnán agus a rialú balbh féin ag gach aschur. Cliceáil ar ainm aschuir chun é a roghnú mar an réamhshocrú. Ar Linux , baineann sé seo le hathsheinm nua agus feictear gach sruth app ar leithligh.

### Rialuithe taispeáint Windows

Coigeartaigh gile ar mhonatóirí tacaithe, téigh an taispeáint leis an scagaire solas gorm, agus bain úsáid as maolú bogearraí ón meascthóir céanna. [Féach ar an screenshot Windows ag méid iomlán](assets/readme/screenshot.png).

### Rialuithe tráidire

Cliceáil ar chlé ar an deilbhín tráidire Windows chun an meascthóir a thaispeáint nó a cheilt agus lárchliceáil air chun balbhú a scoránaigh ar an aschur réamhshocraithe. Scrollaigh thar shraith chun é a choigeartú faoi dhá phointe, cliceáil ar dheilbhín an tsraithe fuaime chun balbhú, nó cliceáil ar dheis ar shraith chun é a chur i bhfolach. Athchóirigh sraitheanna folaithe ón roghchlár tráidire. Brúigh <kbd>Esc</kbd> nó cliceáil taobh amuigh chun an eitilt Windows a dhúnadh. Braitheann cad a tharlaíonn nuair tráidire Linux ar do dheasc.

### Cuma, tosaithe agus roghanna

Úsáideann Windows eitilt chothromú. Leanann Linux GNOME dathanna éadrom, dorcha agus accent nó cuireann Gualach, Nord, Catppuccin agus Solas. Is féidir leat tosaithe a chumasú ag logáil isteach ón roghchlár tráidire. Stóráiltear roghanna go háitiúil.

<summary><b>Suiteáil</b></summary>

### Windows 11 · x64 · v3.0.2

1. Íosluchtaigh [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) le haghaidh suiteálaí as líne nó [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) chun an app a rith go díreach.
2. Sa Socrú, roghnaigh Béarla nó Rúisis, an fillteán suiteála agus cibé acu an dtosóidh tú TrayMixer ag síniú isteach. Tá comhéadan an aip i mBéarla. Cruthaíonn an socrú aicearraí roghchlár deisce agus Tosaigh.
3. Cliceáil ar an deilbhín TrayMixer sa limistéar fógra chun an meascthóir a oscailt.

Rith an Socrú arís chun nuashonrú nó athshuiteáil a dhéanamh agus na sainroghanna agus an rogha uath-thosaithe á gcoinneáil agat. Bain an app trí Windows **Aipeanna suiteáilte**.

Tá na heisiúintí gan síniú, mar sin féadfaidh Windows rabhadh SmartScreen a thaispeáint. Déan comparáid idir SHA -256 an chomhaid leis an [Nótaí scaoileadh Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Chun suiteáil gan duine a dhéanamh gan an aip a sheoladh, rith `TrayMixer-Setup.exe /S /NOLAUNCH` ón bhfillteán suiteálaí. Áirítear lasca roghnacha `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` agus `/LAUNCH`. Chun é a bhaint gan duine, rith `Uninstall.exe /uninstall /S` ón bhfillteán suiteála, a réamhshocrú go `%LOCALAPPDATA%\TrayMixer`.

### Réamhamharc Linux · x86_64 · v3.1.1

| Pacáiste | Suiteáil nó seoladh ón bhfillteán íoslódála |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, ansin `./TrayMixer-3.1.1-x86_64.AppImage` |

Úsáideann an réamhamharc X11 nó XWayland agus teastaíonn glibc 2.35 +, PulseAudio 15+ nó PipeWire-Pulse, agus `pactl`. Éilíonn GNOME tacaíocht AppIndicator le haghaidh íocón an tráidire. Tá leabharlanna deisce córais ag teastáil ón AppImage agus glacann sé leis `--appimage-extract-and-run` mura bhfuil FUSE ar fáil.

Féach ar an [Linux lámhleabhar](linux/README.md) le haghaidh riachtanais deisce agus iompar tráidire. Déan comparáid idir hashes pacáiste le [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>Forbairt</b></summary>

TrayMixer á chothabháil ag [Vlad ( sailxx )](https://github.com/sailxx) faoi ​​na [Ceadúnas Apache 2.0](LICENSE).

Tóg Windows ó chlón leis an ionsuite . Tiomsaitheoir Creat C# NET.

```cmd
build.cmd
```

Tóg Linux le . NET SDK 10.0 . Féach ar an [Treoir maidir le tógáil agus pacáistiú Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Chun an saothar ealaíne Béarla README a atógáil, úsáid na clónna Golos Text agus JetBrains Mono i `tools/readme/.font` mar a thuairiscítear i [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Chun íoslódáil a fhíorú, bain úsáid as `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` i PowerShell agus i gcomparáid leis an [Nótaí scaoileadh Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), nó úsáid `sha256sum <filename>` ar Linux agus cuir i gcomparáid le [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

Stórálann TrayMixer roghanna go háitiúil. Seolann Linux orduithe fuaime chuig do fhreastalaí cumraithe PulseAudio nó PipeWire-Pulse. Féach ar an [polasaí príobháideachta](PRIVACY.md) agus [polasaí slándála](SECURITY.md). Le haghaidh fabht in-atáirgthe, cuir an leagan, OS , deasc agus crua-earraí lena mbaineann san áireamh i [GitHub eisiúint](https://github.com/sailxx/TrayMixer/issues).
