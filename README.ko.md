# TrayMixer

**Windows 11 또는 Linux 시스템 트레이에 있는 하나의 작은 패널에서 모든 출력과 앱의 볼륨을 제어하세요.**

통화음이 들리도록 하면서 게임을 끄고, 스피커와 헤드폰 간을 전환하거나, Windows의 밝기, 블루라이트 필터링 및 밝기 조절을 조정하세요.

**원격 분석이나 계정이 없습니다.** Apache 2.0 아래의 오픈 소스.

### 출력 및 앱 볼륨

각 출력에는 자체 슬라이더와 음소거 컨트롤이 있습니다. 출력 이름을 클릭하여 기본값으로 선택합니다. Linux에서는 이는 새로운 재생에 적용되며 각 앱 스트림은 별도로 표시됩니다.

### Windows 디스플레이 컨트롤

지원되는 모니터의 밝기를 조정하고, 블루라이트 필터로 디스플레이를 따뜻하게 하고, 동일한 믹서에서 소프트웨어 디밍을 사용하세요. [Windows 스크린샷을 전체 크기로 확인하세요](assets/readme/screenshot.png).

### 트레이 컨트롤

믹서를 표시하거나 숨기려면 Windows 트레이 아이콘을 마우스 왼쪽 버튼으로 클릭하고, 기본 출력에서 ​​음소거를 전환하려면 마우스 가운데 버튼을 클릭하세요. 행 위로 스크롤하여 두 포인트씩 조정하고, 오디오 행의 아이콘을 클릭하여 음소거하거나, 행을 마우스 오른쪽 버튼으로 클릭하여 숨깁니다. 트레이 메뉴에서 숨겨진 행을 복원합니다. 누르다 <kbd>Esc</kbd> 또는 외부를 클릭하여 Windows 플라이아웃을 닫습니다. Linux 트레이 클릭은 데스크탑에 따라 다릅니다.

### 모양, 시작 및 기본 설정

Windows는 둥근 플라이아웃을 사용합니다. Linux는 GNOME 밝은 색상, 어두운 색상 및 액센트 색상을 따르거나 Charcoal, Nord, Catppuccin 및 Light를 제공합니다. 트레이 메뉴에서 로그인 시 시작을 활성화할 수 있습니다. 기본 설정은 로컬에 저장됩니다.

### Windows 11 · x64 · v3.0.2

1. 다운로드 [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) 오프라인 설치 프로그램의 경우 또는 [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) 앱을 직접 실행하려면
2. 설정에서 영어 또는 러시아어, 설치 폴더 및 로그인 시 TrayMixer 시작 여부를 선택합니다. 앱 인터페이스는 영어로 되어 있습니다. 설치 프로그램은 바탕 화면 및 시작 메뉴 바로 가기를 만듭니다.
3. 알림 영역에서 TrayMixer 아이콘을 클릭하여 믹서를 엽니다.

기본 설정과 자동 시작 선택을 유지하면서 업데이트하거나 다시 설치하려면 설치 프로그램을 다시 실행하세요. Windows를 통해 앱 제거 **설치된 앱**.

릴리스가 서명되지 않았으므로 Windows에서 SmartScreen 경고가 표시될 수 있습니다. 파일의 SHA -256을 [Windows 릴리스 노트](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

앱을 실행하지 않고 무인 설치를 하려면 다음을 실행하세요. `TrayMixer-Setup.exe /S /NOLAUNCH` 설치 프로그램 폴더에서. 옵션 스위치에는 다음이 포함됩니다. `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` 그리고 `/LAUNCH`. 무인 제거를 위해서는 다음을 실행하십시오. `Uninstall.exe /uninstall /S` 기본적으로 설치 폴더에서 `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 미리보기

| 패키지 | 다운로드 폴더에서 설치 또는 실행 |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, 그 다음에 `./TrayMixer-3.1.1-x86_64.AppImage` |

미리보기에서는 X11 또는 XWayland를 사용하고 glibc 2.35 +, PulseAudio 15+ 또는 PipeWire-Pulse가 필요합니다. `pactl`. GNOME는 트레이 아이콘에 대한 AppIndicator 지원이 필요합니다. AppImage에는 시스템 데스크탑 라이브러리가 필요하며 다음을 허용합니다. `--appimage-extract-and-run` FUSE를 사용할 수 없는 경우.

참조 [Linux 가이드](linux/README.md) 데스크탑 요구 사항 및 트레이 동작을 위해. 패키지 해시를 다음과 비교합니다. [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<details>
<summary><b>개발</b></summary>

TrayMixer는 다음에 의해 유지 관리됩니다. [블라드 (sailxx)](https://github.com/sailxx) 아래에 [아파치 라이센스 2.0](LICENSE).

짓다 Windows .NET 프레임워크 C# 컴파일러.

```cmd
build.cmd
```

짓다 Linux 와 함께 .NET SDK 10.0. 참조 [Linux 빌드 및 패키징 가이드](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

영어 README 아트워크를 다시 작성하려면 다음에서 Golos Text 및 JetBrains Mono 글꼴을 사용하십시오. `tools/readme/.font` 에 설명된 대로 [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

다운로드를 확인하려면 다음을 사용하세요. `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` PowerShell에서 비교하고 [Windows 릴리스 노트](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), 또는 사용 `sha256sum <filename>` Linux에서 다음과 비교 [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer는 기본 설정을 로컬에 저장합니다. Linux는 구성된 PulseAudio 또는 PipeWire-Pulse 서버에 오디오 명령을 보냅니다. 참조 [개인 정보 보호 정책](PRIVACY.md) 그리고 [보안 정책](SECURITY.md). 재현 가능한 버그의 경우 OS 버전, 데스크톱 및 영향을 받는 하드웨어를 [GitHub 문제](https://github.com/sailxx/TrayMixer/issues).

</details>
