# TrayMixer

**Controlați volumul fiecărei ieșiri și aplicații dintr-un panou mic din tava de sistem Windows 11 sau Linux.**

Opriți un joc în timp ce vă păstrați apelul audibil, comutați între difuzoare și căști sau reglați luminozitatea, filtrarea luminii albastre și diminuarea luminii pe Windows.

**Fără telemetrie sau cont.** Sursă deschisă sub Apache 2.0.

<summary><b>Mai multe despre caracteristici</b></summary>

### Ieșiri și volumul aplicației

Fiecare ieșire are propriul glisor și controlul de sunet. Faceți clic pe un nume de ieșire pentru a-l selecta ca implicit. Pe Linux , acest lucru se aplică redării noi și fiecare flux de aplicație apare separat.

### comenzile afișajului Windows

Reglați luminozitatea pe monitoarele acceptate, încălziți afișajul cu filtrul de lumină albastră și utilizați software-ul de reglare a luminii de la același mixer. [Vedeți captura de ecran Windows la dimensiune completă](assets/readme/screenshot.png).

### Comenzi pentru tavă

Faceți clic stânga pe pictograma tăvii Windows pentru a afișa sau ascunde mixerul și faceți clic cu mijlocul pe el pentru a comuta la dezactivarea ieșirii implicite. Derulați peste un rând pentru a-l ajusta cu două puncte, faceți clic pe pictograma unui rând audio pentru a dezactiva sunetul sau faceți clic dreapta pe un rând pentru a-l ascunde. Restaurați rândurile ascunse din meniul tavă. Presa <kbd>Esc</kbd> sau faceți clic afară pentru a închide fereastra Windows. Clicurile pe tavă Linux depind de desktopul dvs.

### Aspect, pornire și preferințe

Windows folosește un derulant rotunjit. Linux urmează culorile deschise, închise și de accent GNOME sau oferă Charcoal, Nord, Catppuccin și Light. Puteți activa pornirea la autentificare din meniul tavă. Preferințele sunt stocate local.

<summary><b>Instala</b></summary>

### Windows 11 · x64 · v3.0.2

1. Descărcați [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) pentru un program de instalare offline sau [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) pentru a rula aplicația direct.
2. În Configurare, alegeți engleză sau rusă, folderul de instalare și dacă să porniți TrayMixer la conectare. Interfața aplicației este în engleză. Configurarea creează comenzi rapide pentru desktop și meniul Start.
3. Faceți clic pe pictograma TrayMixer din zona de notificare pentru a deschide mixerul.

Rulați din nou Setup pentru a actualiza sau a reinstala, păstrând preferințele și opțiunea de pornire automată. Eliminați aplicația prin Windows **Aplicații instalate**.

Versiunile sunt nesemnate, așa că Windows poate afișa un avertisment SmartScreen. Comparați fișierul SHA -256 cu fișierul [Note de lansare Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Pentru o instalare nesupravegheată fără a lansa aplicația, rulați `TrayMixer-Setup.exe /S /NOLAUNCH` din folderul de instalare. Întrerupătoarele opționale includ `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` şi `/LAUNCH`. Pentru îndepărtarea nesupravegheată, alergați `Uninstall.exe /uninstall /S` din folderul de instalare, care este implicit `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 previzualizare

| Pachet | Instalați sau lansați din folderul de descărcare |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, apoi `./TrayMixer-3.1.1-x86_64.AppImage` |

Previzualizarea folosește X11 sau XWayland și necesită glibc 2.35 +, PulseAudio 15+ sau PipeWire-Pulse și `pactl`. GNOME necesită suport AppIndicator pentru pictograma tavă. AppImage are nevoie de biblioteci desktop de sistem și acceptă `--appimage-extract-and-run` dacă FUSE nu este disponibil.

Vezi [Ghid Linux](linux/README.md) pentru cerințele desktopului și comportamentul tăvii. Comparați hashurile de pachet cu [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>Dezvoltare</b></summary>

TrayMixer este întreținut de [Vlad ( sailxx )](https://github.com/sailxx) sub [Licență Apache 2.0](LICENSE).

Construiți Windows dintr-o clonă cu . Compilatorul NET Framework C#.

```cmd
build.cmd
```

Construiți Linux cu . NET SDK 10.0 . Vezi [Ghid de construcție și ambalare Linux](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Pentru a reconstrui ilustrația engleză README, utilizați fonturile Golos Text și JetBrains Mono în `tools/readme/.font` așa cum este descris în [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Pentru a verifica o descărcare, utilizați `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` în PowerShell și comparați cu [Note de lansare Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), sau utilizați `sha256sum <filename>` pe Linux și comparați cu [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer stochează preferințele local. Linux trimite comenzi audio către serverul dvs. configurat PulseAudio sau PipeWire-Pulse. Vezi [Politica de confidențialitate](PRIVACY.md) şi [politica de securitate](SECURITY.md). Pentru o eroare reproductibilă, includeți versiunea, OS, desktop și hardware-ul afectat într-un [Problema GitHub](https://github.com/sailxx/TrayMixer/issues).

</details>
