# TrayMixer

**Керуйте гучністю кожного виводу та програми з однієї невеликої панелі в панелі завдань Windows 11 або Linux.**

Вимкніть гру, щоб ваш дзвінок був чутний, перемикайтеся між динаміками та навушниками або регулюйте яскравість, фільтрацію синього світла та затемнення на Windows.

**Немає телеметрії чи облікового запису.** Відкритий код під Apache 2.0.

<summary><b>Детальніше про особливості</b></summary>

### Виходи та обсяг програми

Кожен вихід має власний повзунок і регулятор відключення звуку. Клацніть назву виводу, щоб вибрати її за замовчуванням. На Linux це стосується нового відтворення, і кожен потік програми відображається окремо.

### Елементи керування дисплеєм Windows

Налаштуйте яскравість на підтримуваних моніторах, зігрійте дисплей за допомогою фільтра синього світла та використовуйте програмне затемнення з того самого мікшера. [Перегляньте знімок екрана Windows у повному розмірі](assets/readme/screenshot.png).

### Елементи керування треєм

Клацніть лівою кнопкою миші значок Windows в треї, щоб показати або приховати мікшер, і клацніть його середньою кнопкою миші, щоб увімкнути звук на виході за замовчуванням. Прокрутіть рядок, щоб відрегулювати його на дві точки, клацніть піктограму рядка аудіо, щоб вимкнути звук, або клацніть рядок правою кнопкою миші, щоб приховати його. Відновити приховані рядки з меню трея. Прес <kbd>Esc</kbd> або клацніть зовні, щоб закрити спадне вікно Windows. Клацання лотка Linux залежить від робочого столу.

### Зовнішній вигляд, запуск і налаштування

Windows використовує заокруглену панель. Linux слідує за світлими, темними та акцентними кольорами GNOME або пропонує Charcoal, Nord, Catppuccin та Light. Ви можете ввімкнути запуск під час входу в трей меню. Налаштування зберігаються локально.

<summary><b>встановити</b></summary>

### Windows 11 · x64 · v3.0.2

1. Завантажити [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) для офлайн-інсталятора або [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) щоб запустити програму безпосередньо.
2. У налаштуваннях виберіть англійську чи російську, папку встановлення та чи запускати TrayMixer під час входу. Інтерфейс програми англійською мовою. Програма встановлення створює ярлики робочого столу та меню «Пуск».
3. Натисніть піктограму TrayMixer в області повідомлень, щоб відкрити мікшер.

Знову запустіть програму встановлення, щоб оновити або перевстановити, зберігаючи параметри та вибір автозапуску. Видаліть додаток через Windows **Встановлені програми**.

Випуски непідписані, тому Windows може відображати попередження SmartScreen. Порівняйте файл SHA -256 із [Примітки до випуску Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

Для автоматичного встановлення без запуску програми запустіть `TrayMixer-Setup.exe /S /NOLAUNCH` з папки інсталятора. Додаткові перемикачі включають `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` і `/LAUNCH`. Для видалення без нагляду запустіть `Uninstall.exe /uninstall /S` з папки інсталяції, яка є за замовчуванням `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 попередній перегляд

| Пакет | Встановіть або запустіть із папки завантажень |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, потім `./TrayMixer-3.1.1-x86_64.AppImage` |

Попередній перегляд використовує X11 або XWayland і потребує glibc 2.35 +, PulseAudio 15+ або PipeWire-Pulse та `pactl`. Для GNOME потрібна підтримка AppIndicator для значка в треї. Для AppImage потрібні системні бібліотеки робочого столу, і він приймає `--appimage-extract-and-run` якщо FUSE недоступний.

Див [Посібник Linux](linux/README.md) для вимог робочого столу та поведінки трея. Порівняйте хеші пакетів із [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

</details>

<summary><b>розвиток</b></summary>

TrayMixer підтримується [Влад ( sailxx )](https://github.com/sailxx) під [Ліцензія Apache 2.0](LICENSE).

Збірка Windows з клону з вбудованим . Компілятор C# NET Framework.

```cmd
build.cmd
```

Збірка Linux з . NET SDK 10.0 . Див [Linux Посібник зі збірки та пакування](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

Щоб відновити англійську ілюстрацію README, використовуйте шрифти Golos Text і JetBrains Mono у `tools/readme/.font` як описано в [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

Щоб підтвердити завантаження, використовуйте `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` в PowerShell і порівняти з [Примітки до випуску Windows](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), або використовувати `sha256sum <filename>` на Linux і порівняти з [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer зберігає налаштування локально. Linux надсилає звукові команди на налаштований сервер PulseAudio або PipeWire-Pulse. Див [політика конфіденційності](PRIVACY.md) і [політика безпеки](SECURITY.md). Для відтворюваної помилки вкажіть версію, OS, робочий стіл і уражене обладнання в a [Проблема GitHub](https://github.com/sailxx/TrayMixer/issues).

</details>
