# TrayMixer

**کوئی ٹیلی میٹری یا اکاؤنٹ نہیں۔** Apache 2.0 کے تحت اوپن سورس۔

### آؤٹ پٹ اور ایپ والیوم

ہر آؤٹ پٹ کا اپنا سلائیڈر اور خاموش کنٹرول ہوتا ہے۔ آؤٹ پٹ نام کو بطور ڈیفالٹ منتخب کرنے کے لیے اس پر کلک کریں۔ Linux پر، یہ نئے پلے بیک پر لاگو ہوتا ہے اور ہر ایپ کا سلسلہ الگ سے ظاہر ہوتا ہے۔

### Windows ڈسپلے کنٹرولز

معاون مانیٹر پر چمک کو ایڈجسٹ کریں، نیلی روشنی والے فلٹر کے ساتھ ڈسپلے کو گرم کریں، اور اسی مکسر سے مدھم ہونے والا سافٹ ویئر استعمال کریں۔ [مکمل سائز میں Windows اسکرین شاٹ دیکھیں](assets/readme/screenshot.png).

### ٹرے کنٹرولز

مکسر کو دکھانے یا چھپانے کے لیے Windows ٹرے آئیکن پر بائیں کلک کریں اور ڈیفالٹ آؤٹ پٹ پر خاموش ٹوگل کرنے کے لیے اس پر درمیانی کلک کریں۔ قطار کو دو پوائنٹس سے ایڈجسٹ کرنے کے لیے اس پر اسکرول کریں، خاموش کرنے کے لیے آڈیو قطار کے آئیکن پر کلک کریں، یا کسی قطار کو چھپانے کے لیے اس پر دائیں کلک کریں۔ ٹرے مینو سے چھپی ہوئی قطاروں کو بحال کریں۔ دبائیں <kbd>Esc</kbd> یا Windows فلائی آؤٹ کو بند کرنے کے لیے باہر کلک کریں۔ Linux ٹرے کلکس آپ کے ڈیسک ٹاپ پر منحصر ہیں۔

### ظاہری شکل، آغاز اور ترجیحات

Windows ایک گول فلائی آؤٹ استعمال کرتا ہے۔ Linux GNOME ہلکے، گہرے اور لہجے والے رنگوں کی پیروی کرتا ہے یا چارکول، نورڈ، کیٹپپوسن اور لائٹ پیش کرتا ہے۔ آپ ٹرے مینو سے لاگ ان پر اسٹارٹ اپ کو فعال کر سکتے ہیں۔ ترجیحات مقامی طور پر محفوظ کی جاتی ہیں۔

### Windows 11 · x64 · v3.0.2

1. ڈاؤن لوڈ کریں۔ [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) ایک آف لائن انسٹالر کے لیے یا [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) ایپ کو براہ راست چلانے کے لیے۔
2. سیٹ اپ میں، انگریزی یا روسی، انسٹال فولڈر کا انتخاب کریں اور آیا سائن ان کرتے وقت TrayMixer شروع کرنا ہے۔ ایپ کا انٹرفیس انگریزی میں ہے۔ سیٹ اپ ڈیسک ٹاپ اور اسٹارٹ مینو شارٹ کٹ بناتا ہے۔
3. مکسر کھولنے کے لیے نوٹیفکیشن ایریا میں TrayMixer آئیکن پر کلک کریں۔

ترجیحات اور آٹو سٹارٹ انتخاب کو برقرار رکھتے ہوئے اپ ڈیٹ یا دوبارہ انسٹال کرنے کے لیے دوبارہ سیٹ اپ چلائیں۔ Windows کے ذریعے ایپ کو ہٹا دیں۔ **انسٹال کردہ ایپس**.

ریلیز غیر دستخط شدہ ہیں، لہذا Windows اسمارٹ اسکرین وارننگ دکھا سکتا ہے۔ فائل کا SHA -256 کے ساتھ موازنہ کریں۔ [Windows ریلیز نوٹ](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

ایپ کو لانچ کیے بغیر کسی غیر توجہ شدہ انسٹال کے لیے، چلائیں۔ `TrayMixer-Setup.exe /S /NOLAUNCH` انسٹالر فولڈر سے۔ اختیاری سوئچز شامل ہیں۔ `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` اور `/LAUNCH`. بغیر توجہ ہٹانے کے لیے، چلائیں۔ `Uninstall.exe /uninstall /S` انسٹالیشن فولڈر سے، جو پہلے سے طے شدہ ہے۔ `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 پیش منظر

| پیکج | ڈاؤن لوڈ فولڈر سے انسٹال یا لانچ کریں۔ |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, پھر `./TrayMixer-3.1.1-x86_64.AppImage` |

پیش نظارہ X11 یا XWayland استعمال کرتا ہے اور اسے glibc 2.35 +، PulseAudio 15+ یا پائپ وائر پلس کی ضرورت ہے، اور `pactl`. GNOME کو ٹرے آئیکن کے لیے AppIndicator سپورٹ درکار ہے۔ AppImage کو سسٹم ڈیسک ٹاپ لائبریریوں کی ضرورت ہے اور قبول کرتا ہے۔ `--appimage-extract-and-run` اگر FUSE دستیاب نہیں ہے۔

دیکھیں [Linux گائیڈ](linux/README.md) ڈیسک ٹاپ کی ضروریات اور ٹرے کے رویے کے لیے۔ پیکج ہیشز کا موازنہ کریں۔ [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>ترقی</b></summary>

TrayMixer کی طرف سے برقرار رکھا جاتا ہے [ولاد ( sailxx )](https://github.com/sailxx) کے تحت [اپاچی لائسنس 2.0](LICENSE).

بلٹ ان کے ساتھ کلون سے Windows بنائیں۔ NET فریم ورک C# مرتب کرنے والا۔

```cmd
build.cmd
```

کے ساتھ Linux بنائیں۔ NET SDK 10.0 دیکھیں [Linux تعمیر اور پیکیجنگ گائیڈ](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

انگریزی README آرٹ ورک کو دوبارہ بنانے کے لیے، Golos Text اور JetBrains Mono فونٹس کا استعمال کریں `tools/readme/.font` جیسا کہ میں بیان کیا گیا ہے۔ [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

ڈاؤن لوڈ کی تصدیق کرنے کے لیے، استعمال کریں۔ `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` PowerShell میں اور اس کے ساتھ موازنہ کریں۔ [Windows ریلیز نوٹ](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), یا استعمال کریں `sha256sum <filename>` Linux پر اور اس کے ساتھ موازنہ کریں۔ [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer ترجیحات کو مقامی طور پر اسٹور کرتا ہے۔ Linux آپ کے ترتیب شدہ PulseAudio یا PipeWire-Pulse سرور کو آڈیو کمانڈ بھیجتا ہے۔ دیکھیں [رازداری کی پالیسی](PRIVACY.md) اور [سیکورٹی پالیسی](SECURITY.md). دوبارہ پیدا کرنے کے قابل بگ کے لیے، ورژن، OS، ڈیسک ٹاپ اور متاثرہ ہارڈ ویئر کو شامل کریں [GitHub مسئلہ](https://github.com/sailxx/TrayMixer/issues).
