### چىقىرىش ۋە ئەپ مىقدارى

ھەر بىر چىقىرىشنىڭ ئۆزىگە خاس سىيرىلغۇچ ۋە ئاۋازسىز كونترول قىلىش ئىقتىدارى بار. چىقىرىش نامىنى چېكىپ سۈكۈتتىكى ھالەتتە تاللاڭ. Linux دە ، بۇ يېڭى قويۇشقا ماس كېلىدۇ ، ھەر بىر ئەپ ئېقىمى ئايرىم كۆرۈنىدۇ.

### Windows كۆرسىتىش كونتروللىرى

قوللايدىغان ئېكراندىكى يورۇقلۇقنى تەڭشەڭ ، كۆك نۇر سۈزگۈچ بىلەن ئېكراننى قىزىتىڭ ، ئوخشاش ئارىلاشتۇرغۇچتىن يۇمشاق دېتال غۇۋا ئىشلىتىڭ. [چوڭلۇقتىكى Windows ئېكران رەسىمىنى كۆرۈڭ](assets/readme/screenshot.png).

### تەخسە كونتروللىرى

ئارىلاشتۇرغۇچنى كۆرسىتىش ياكى يوشۇرۇش ئۈچۈن Windows تەخسە سىنبەلگىسىنى سول چېكىپ ، ئوتتۇرىنى چېكىپ سۈكۈتتىكى چىقىرىشتا ئاۋازسىز ھالەتكە كېلىدۇ. ئۇنى بىر قۇرغا توغرىلاپ ئىككى نۇقتىغا تەڭشەڭ ، ئاۋاز قۇرنىڭ سىنبەلگىسىنى چېكىپ ئۈنسىز قىلىڭ ياكى بىر قۇرنى ئوڭ چېكىپ يوشۇرۇڭ. تەخسە تىزىملىكىدىن يوشۇرۇن قۇرلارنى ئەسلىگە كەلتۈرۈڭ. Press <kbd>Esc</kbd> ياكى سىرتنى چېكىپ Windows ئۇچۇش يولىنى تاقاڭ. Linux تەخسە چېكىش ئۈستەل يۈزىڭىزگە باغلىق.

### كۆرۈنۈش ، ئىگىلىك تىكلەش ۋە مايىللىق

Windows يۇمىلاق شەكىللىك ئۇچۇش يولىنى ئىشلىتىدۇ. Linux GNOME سۇس ، قېنىق ۋە تەلەپپۇز رەڭلىرىگە ئەگىشىدۇ ياكى كۆمۈر ، Nord ، Catppuccin ۋە Light بىلەن تەمىنلەيدۇ. تەخسە تىزىملىكىدىن كىرىشتە قوزغىتىشنى قوزغىتالايسىز. مايىللىق يەرلىكتە ساقلىنىدۇ.

### Windows 11 · x64 · v3.0.2

1. چۈشۈرۈش [**TrayMixer-Setup.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer-Setup.exe) تورسىز قاچىلىغۇچ ياكى [**TrayMixer.exe**](https://github.com/sailxx/TrayMixer/releases/download/v3.0.2/TrayMixer.exe) ئەپنى بىۋاسىتە ئىجرا قىلىش.
2. تەڭشەشتە ، قاچىلاش قىسقۇچى ۋە تىزىملىتىپ كىرىشتە TrayMixer نى قوزغىتىش ياكى باشلىماسلىقنى تاللاڭ. ئەپ كۆرۈنمە يۈزى ئىنگلىزچە. تەڭشەش ئۈستەلئۈستى ۋە باشلاش تىزىملىكى تېزلەتمىسى قۇرىدۇ.
3. ئارىلاشتۇرغۇچنى ئېچىش ئۈچۈن ئۇقتۇرۇش رايونىدىكى TrayMixer سىنبەلگىسىنى چېكىڭ.

تەڭشەكلەرنى قايتا قوزغىتىپ ، مايىللىق ۋە ئاپتوماتىك تاللاشنى ساقلاش جەريانىدا يېڭىلاش ياكى قايتا قاچىلاش. Windows ئارقىلىق ئەپنى ئۆچۈرۈڭ **قاچىلانغان ئەپلەر**.

تارقىتىلمىغان ، شۇڭا Windows بەلكىم SmartScreen ئاگاھلاندۇرۇشى كۆرسىتىشى مۇمكىن. ھۆججەتنىڭ SHA -256 بىلەن سېلىشتۇرۇڭ [Windows ئېلان قىلىش خاتىرىسى](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2).

ئەپنى ئاچماي تۇرۇپ قاچىلىمىغان قاچىلاش ئۈچۈن ئىجرا قىلىڭ `TrayMixer-Setup.exe /S /NOLAUNCH` قاچىلاش مۇندەرىجىسىدىن. ئىختىيارى ئالماشتۇرغۇچ ئۆز ئىچىگە ئالىدۇ `/DIR="C:\path\TrayMixer"`, `/NOAUTOSTART` ۋە `/LAUNCH`. ئېھتىياتسىزلىقتىن ئېلىۋېتىش ئۈچۈن ئىجرا قىلىڭ `Uninstall.exe /uninstall /S` قاچىلاش مۇندەرىجىسىدىن `%LOCALAPPDATA%\TrayMixer`.

### Linux · x86_64 · v3.1.1 ئالدىن كۆرۈش

| بوغچا | چۈشۈرۈش قىسقۇچىدىن قاچىلاڭ ياكى قوزغىتىڭ |
| --- | --- |
| [DEB](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer_3.1.1_amd64.deb) | `sudo apt install ./TrayMixer_3.1.1_amd64.deb` |
| [RPM](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-1.x86_64.rpm) | `sudo dnf install ./TrayMixer-3.1.1-1.x86_64.rpm` |
| [AppImage](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/TrayMixer-3.1.1-x86_64.AppImage) | `chmod +x TrayMixer-3.1.1-x86_64.AppImage`, ئاندىن `./TrayMixer-3.1.1-x86_64.AppImage` |

ئالدىن كۆرۈشتە X11 ياكى XWayland ئىشلىتىلگەن بولۇپ ، glibc 2.35 + ، PulseAudio 15+ ياكى PipeWire-Pulse ۋە `pactl`. GNOME تەخسە سىنبەلگىسىنى AppIndicator قوللاشنى تەلەپ قىلىدۇ. AppImage سىستېما ئۈستەلئۈستى كۈتۈپخانىلىرىغا ئېھتىياجلىق ۋە قوبۇل قىلىدۇ `--appimage-extract-and-run` ئەگەر FUSE ئىشلەتكىلى بولمىسا.

قاراڭ [Linux يېتەكچىسى](linux/README.md) ئۈستەل يۈزى تەلىپى ۋە تەخسە ھەرىكىتى ئۈچۈن. بوغچا بىلەن سېلىشتۇرۇڭ [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

<summary><b>تەرەققىيات</b></summary>

TrayMixer تەرىپىدىن قوغدىلىدۇ [Vlad (sailxx)](https://github.com/sailxx) ئاستىدا [Apache ئىجازەتنامىسى 2.0](LICENSE).

ئىچىگە قاچىلانغان كلوندىن Windows ياساڭ. NET Framework C # تۈزگۈچى.

```cmd
build.cmd
```

بىلەن Linux نى ياساڭ. NET SDK 10.0. قاراڭ [Linux قۇرۇش ۋە ئوراش يېتەكچىسى](linux/README.md#build-and-verify).

```sh
dotnet build linux/TrayMixer.Linux.csproj -c Release
dotnet run --project linux/tests/TrayMixer.Linux.Tests.csproj -c Release
```

ئىنگلىزچە README سەنئەت ئەسىرىنى قايتا قۇرۇش ئۈچۈن ، Golos Text ۋە JetBrains Mono خەت نۇسخىسىنى ئىشلىتىڭ `tools/readme/.font` تەسۋىرلەنگەندەك [build.mjs](tools/readme/build.mjs).

```sh
cd tools/readme
npm ci
node build.mjs --showcase
```

چۈشۈرۈشنى دەلىللەش ئۈچۈن ئىشلىتىڭ `Get-FileHash .\TrayMixer-Setup.exe -Algorithm SHA256` بىلەن PowerShell بىلەن سېلىشتۇرۇڭ [Windows ئېلان قىلىش خاتىرىسى](https://github.com/sailxx/TrayMixer/releases/tag/v3.0.2), ياكى ئىشلىتىش `sha256sum <filename>` Linux بىلەن سېلىشتۇرۇڭ [SHA256SUMS](https://github.com/sailxx/TrayMixer/releases/download/linux-v3.1.1/SHA256SUMS).

TrayMixer يەرلىكتىكى مايىللىقنى ساقلايدۇ. Linux سەپلەنگەن PulseAudio ياكى PipeWire-Pulse مۇلازىمېتىرىڭىزغا ئاۋازلىق بۇيرۇق ئەۋەتىدۇ. قاراڭ [مەخپىيەتلىك تۈزۈمى](PRIVACY.md) ۋە [بىخەتەرلىك سىياسىتى](SECURITY.md). كۆپەيتكىلى بولىدىغان كەمتۈك ئۈچۈن ، نەشرىدىكى OS ، ئۈستەل يۈزى ۋە تەسىرگە ئۇچرىغان قاتتىق دېتاللارنى ئۆز ئىچىگە ئالىدۇ [GitHub مەسىلىسى](https://github.com/sailxx/TrayMixer/issues).
